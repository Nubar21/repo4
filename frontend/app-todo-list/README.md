# Todo List Project

Это проект туду-листа (лист с задачами) создан для удобного планирования задач и отслеживания их выполнения.

## Описание

Данный проект предназначен для быстрого добавления, редактирования и отметки выполненных задач, что помогает организовать рабочий или личный процесс.

## Особенности

- Добавление новых задач;
- отметка выполненных задач;
- просмотр текущего списка задач;
- простая и понятная структура;
- защита от добавления пустых задач.

## Установка

Чтобы начать работу с этим проектом, выполните следующие шаги:
- Откройте терминал и выполните команду:

```bash
git clone https://github.com/Nubar21/repo4.git
```
Это создаст копию проекта на вашем компьютере.

- Перейдите в директорию проекта:
```bash
cd repo4
```

- Перед началом работы рекомендуется создать отдельную/локальную ветку:
```bash
git checkout -b название-вашей-ветки
```
- Вносите нужные изменения в код с помощью вашей IDE или редактора кода.
- При завершении изменений добавьте их в коммит:
```bash
git add .
git commit -m "Описание внесенных изменений"
```

- Пушите свою ветку на удаленный репозиторий:
```bash
git push -u origin название-вашей-ветки
```
- Перейдите на страницу вашего репозитория на GitHub и создайте Pull Request для объединения своих изменений с основной веткой.
